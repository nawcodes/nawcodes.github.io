Tentang Saya

Hi, saya Rifal Nurjamil, saya seorang Software Enginer Di bagian Back End Developer. Domisili saya dari Kab. Sukabumi, Jawa Barat. Saya memiliki passion yang besar dalam dunia komputer dan teknologi. Saya juga memiliki passion menjadi seorang penguasaha yang alih alih saat ini masih merintis dan masih banyak kekurangan, tapi saya akan terus belajar dan berusaha untuk menjadi yang terbaik.

Awal kenalan saya dengan dunia teknologi yaitu saat saya masih duduk di bangku SMK, saya mengambil jurusan Teknik Komputer dan Jaringan. Lanjut ke perguruan tinggi saya mengambil jurusan Sistem Informasi di Universitas Nusa Putra Sukabumi. Saya mendalami dunia software enginer secara otodidak dan juga mengikuti kursus di beberapa platform online selama 4 tahun lamanya.

Karier saya di dunia kerja di mulai dari beberapa perusahaan terkemuka. saya mendapakan kesempatan untuk terlibat dalam proyek proyek menarik dan bertanggung jawab atas pengembangan aplikasi web. Saat ini saya sedang menempati sebagai Full Stack Developer di DevHunt Software House.
